## 对原文美术方法的运用

设计依据为原材料 26:16—28:35 所述的第一印象、技术报告式呈现、方法名称与任务结合，以及内容明确后再打磨美感。原材料没有提供图像，因此这些图是本项目的原创设计，不声称复刻原视频或某篇参考论文。

宣传图将 **insight-paper** 的名称与其任务结合：多篇研究材料通过一个珊瑚色折纸焦点汇聚为完整论文。纸张、洞见和成稿共同构成品牌隐喻。图中文字为品牌名称与流程概括，页面纹样不代表论文实验数据。

架构图沿用宣传图的暖白、炭黑、灰青和珊瑚色。珊瑚色明确标出 insight 与实验论证；实线表示主流程，虚线表示结果反馈和资料复用。动机分析进入 Method 的原则单独强调，底部共享状态带说明如何从已有进度继续。

## 来源与编辑

- 宣传图由 OpenAI 图像生成工具为本项目生成，保留原始 PNG 文件。它是宣传情境资产，不是科学实验结果。
- 架构内容来自本仓库的技能入口、阶段参考和辅助技能调用表；所有文字、矩形和连接关系均为原生可编辑元素，没有嵌入宣传图作为流程。
- 架构图 SVG 根据 draw.io 文件中的几何、文字和边关系导出；PNG 与 PDF 由浏览器渲染 SVG。直接用 draw.io 再次导出时，字体和圆角可能有轻微差异。
- 字体依次使用 PingFang SC、Noto Sans CJK SC、Microsoft YaHei、Helvetica Neue 和 Arial。仓库不附带字体文件；不同系统如需固定排版，可使用 PNG 或 PDF。
- 原始视频、论文图像和其他项目图标未被复制进这些图。

## 检查记录

完成三轮实际导出检查，第三轮包括 960px README 显示宽度。检查结果如下：

| 检查项 | 第一轮 | 第二轮 | 第三轮与交付检查 |
|---|---|---|---|
| 文字 | 放大正文和长技能名称 | 发现两处实际文字宽度略超预留框，改用薄空格 | 51 个文字对象无预留宽度溢出，无画布裁切 |
| 箭头 | 增大箭头尖端 | 核对 5 条主路径、反馈和复用关系 | 7 条关系方向明确，无穿字或穿卡 |

| 间距 | 收窄过大的编辑文本选区 | 检查行距与内边距 | README 缩放后保持对齐 |
| 配色 | 明确珊瑚色对应核心论证 | 对照宣传图 | 与规范色值一致 |
| 字体 | 区分标题、正文与注释 | 提高长技能名字号 | 字体层级清楚 |

| 图标 | 只保留阶段编号 | 无无意义装饰图标 | 没有外部图标或图像依赖 |
| 风格与语义 | 明确 G 为故事验证 | 不把实验设计画成自动训练 | 与真实 skill 内容对应 |

`validate_drawio.py` 通过：无重复 ID、无占位标签、无嵌入位图或外链图像。`validate_visual_quality.py` 为零 FAIL；9 个空背景框 WARN 均来自卡片背景与独立文字分层，已对照实际图逐项确认。

最终反向检查再次覆盖上述九项，未发现需要阻止交付的问题。自评为 46/50：文字9、箭头9、配色10、构图9、风格9。保留的取舍是长技能名需要较多阅读注意力、资料复用线横跨整排阶段、共享状态层比主流程更疏，以及矢量架构采用平面表达而非宣传图的纸张质感。窄屏可打开高清图查看。
