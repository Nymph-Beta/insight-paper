# 从动机实验到故事与论文

## 实验按论证功能分类

已安装时调用 `ccf-experiment-designer` 细化数据、基线、指标和执行安排；否则直接按本节形成方案。两种方式都保留本工作流的分类与位置：

| 类型 | 主要问题 | 通常的论文位置 |
|---|---|---|
| M：动机/诊断 | 为什么需要这种设计，核心解释是否有依据？ | Method 前段、设计依据或紧邻方法的分析节 |
| P：主要性能 | 效果是否有竞争力，代价如何？ | 主结果 |
| A：消融 | 已提出模块/选择是否有效？ | 消融分析 |
| G：故事扩展 | 反直觉发现能否被解释，是否跨任务有效？ | 分析、泛化或对应主张附近 |

稳健性、失败案例、效率等按论文主张纳入 P/G 或独立条目；不为了字段齐全无条件加实验。M 不能被“A去掉模块”的清单吞并；G 的通用性验证也不能只用原任务不同数据划分代替不同任务。

每项在 `experiment-plan.md` 记录：`ID、主张/问题、数据、比较对象、控制变量、测量与指标方向、实施步骤、所需资源、支持/相反分支、拟展示图表、论文位置、真实结果路径或 pending`。M 额外记录“分析如何引出方法”；A 记录“移除/替换哪个已提出组件”。

在 `claim-evidence.md` 连接 `insight → M观察 → 设计原则 → 方法 → P/A/G → 论文句子与图表`。内部 ID 用于追踪，不强迫进入最终论文行文。

## 结果和投入的原文要求

保留定量结果达到 SOTA 的目标，同时不要把所有投入锁定在大表格中的微小提升。设计时明确要比较的最新适配基线与条件；结果呈现时保留真实值、精度、单位、种子、统计量和成本信息。

加粗严格依据实际指标方向和比较结果。没有领先的指标应显眼说明已有依据；原因未知就标记待分析。不要隐藏未领先项或把合理解释写成未经验证的事实。没有数字时用 `TBD`，不声称已经满足SOTA目标。

反直觉和通用性所需的分析同样占用实验资源。将预算与优先顺序跟主张的依赖对应：先做能决定核心解释是否值得推进的 M，再安排主性能和必要的 A/G；已有真实结果可直接整理，不要求按固定时间表重跑。

本 skill 默认设计实验并使用已有结果；训练、数据采购、付费算力和长时作业按用户任务授权执行。不能把“三四个月一篇”的原文经验变成硬性进度或录用保证。

## 结果回来以后

逐项将 pending 更新为支持/部分支持/不支持，保留来源。

- 支持：将相应假设升级为观察或证据支持的主张，并明确范围。
- 部分支持：收窄适用条件，保留其他项及其解释状态。
- 不支持：更新 insight 与 storyline；可以提出新解释/新机制作为显式变体，不把原本失败的动机改名成成功消融。

后续文献出现相近工作时，更新最接近工作的差异说明和证据要求，不丢弃已完成研究。

## 组织故事

在 `storyline.md` 用一句主线贯穿：

`问题与已有假设 → 值得解释的现象 → 系统分析 → 核心洞见 → 设计原则与方法 → 结果与适用范围`。

保留原文的三个叙事层次：

1. 基础：合乎逻辑，且有经过文献对照的新内容；不凑贡献数。
2. 反直觉方向：有来源的常见预期 → 意外现象 → 详细证明、实验或推导 → 能被理解的新认识。没有意外现象时不要强造冲突。
3. 通用方向：同一机制在多个有意义的任务中接受验证，例如原文提及深度估计与语义分割。按真实证据界定范围。

后两项是可选叙事方向，不要求同时实现。引用原文时保留其“基础对应普通poster、更突出故事更难且可遇不可求”的作者经验属性，不将其写成会议规则或分数承诺。

从已读参考论文提炼段落角色、动机到方法的连接、证据的出场顺序；借鉴结构，不复制独特表达、贡献或数字。

## 写成稿件

已有完整流程授权且已安装时，按实际任务调用 `ccf-paper-writer`，提供选中 idea、insight 卡、文献证据矩阵、实验状态和视觉计划；未安装时按这些材料直接起草。仅需研究方案时停在方案，不自动扩成完整论文。

建议把 Method 写作组织为：

- 任务定义与必要前提；
- 有来源的系统分析/动机实验；
- 从观察到设计原则的过渡；
- 方法机制、模块与必要形式化。

这是本工作流的论证组织方式，用户给定结构优先。Results 部分再放 P 类比较、A 类消融，以及与故事相关的 G 类分析；可根据文章逻辑调整位置，但不能抹去 M 的独立功能。

结果未完成时可以交付假设式研究方案或明确标注待补的稿件，不用“我们证明/取得最优”代替待跑实验。实际写作与实验真实时间顺序不同也不能虚构研究历史。

## 每轮续作

在 `project-state.md` 更新：用户目标与终点、领域/会议/日期窗口、原始 idea 与选中机制、资料位置、insight版本、实验和主张状态、storyline/稿件路径、已看风格参考、下一项独立可执行动作。依赖未满足只限制对应环节，继续其他已有证据支持的工作。
