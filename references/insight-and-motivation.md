# 从 idea 到 insight，再到方法动机

## 包装的具体工作

idea 是“准备做什么”；insight 是“看到了什么关键关系，因此这件事值得做”。保留任务、输入输出、方法机制、约束和用户选择，把 idea 提炼成能统领分析、实验和叙事的一句话。一个优秀 insight 可以支撑论文，不为了贡献列表凑三个模块。

先保存 `raw_idea`、`mechanism_to_preserve`、`user_constraints`。如果更好的解释需要换机制，另写 `optional_variant` 和改变点，主卡仍围绕原机制。用户选择变体后才更新选中主线，保留变更记录。

## Insight 卡的必要内容

写入 `insight.md`，用自然语言填具体内容：

| 项目 | 内容 |
|---|---|
| 原始 idea 与不变项 | 用户/brainstorm选中的具体操作、任务和机制 |
| 现有做法与假设 | 前人怎样做、隐含依赖什么；绑定论文页/节，推断需标记 |
| 现象或张力 | 文献/已有实验中什么现象值得解释；无观察时称待检验现象 |
| 解释性判断 | 为什么可能出现该现象，什么因素可能是关键 |
| 设计原则 | 这项解释如果成立，方法应遵循什么原则 |
| 最小方法联系 | 原 idea 如何落实这一原则；不要只换术语或起新名字 |
| 可检验预测 | 哪些比较、变化趋势或干预可以区分本解释与其他解释 |
| 支持与相反结果 | 预先写明两种结果怎样影响主张，不只列期望成功的分支 |
| 主张范围与状态 | 文献支持 / 初步观察 / 待验证 / 部分支持 / 不支持；适用条件 |
| 两种表达 | 内部直白解释；可用于论文的精炼表述，强度随证据状态 |
| 可选变体 | 改变任务或机制的方案单列，不替代原主线 |

可以使用这条表达骨架，但按证据自然改写：

> 已有做法通常以 X 处理 Y。观察/待检验现象 Z 提示，关键因素可能是 W。由此，我们研究原则 P，并用方法 M 实现；其成立应在实验 E 中表现为 R。

证据尚未出现时使用“我们假设/拟检验”，不要用“我们发现/实验证明”。“反直觉”要说明具体反对哪个有来源的预期；通用性要列出候选任务及证据需求，不能仅改标题就获得这两种性质。

## 优先设计动机实验

从 insight 的“现象—解释—设计原则”出发，为每个重要连接设计一个可观察的比较。先问“什么事实能使这种设计有必要”，再问“最终模块有没有效果”。

动机实验记录为 M 类，至少包含：

`问题/现有假设 → 数据与分析对象 → 控制条件与干预/分组 → 测量量 → 支持分支与相反分支 → 图表 → 方法设计联系 → 放置位置`。

**放置位置必须写为 Method 前段的动机分析、设计依据，或紧邻方法的独立分析节，并写出从分析结论过渡到设计原则的段落草稿。**用户既定结构不适合时适配位置，但保持“先让读者理解设计来由”的论证功能。

原文的例子：比较 1000/600/200/1 步与不同 prediction 形式，解释减少步数的依据；可视化 latent/feature 展示模型内部现象；折线图用于说明变化。将这些作为分析形式借鉴，不机械套用这些步数、模型或结论。

动机分析与消融分开：动机分析可以使用已有模型或基础设定，检验提出方法之前就值得回答的问题；消融在已提出方法上移除/替换模块，验证设计是否有效。方法里的论述顺序也不等于真实研究的时间顺序，不虚构“先发现后设计”的实验历史。

## 完整示例：区域自适应推理步数

这是结构示例，下面的关系均为待验证假设，不是真实实验结果或新颖性结论。

- 原 idea：根据区域不确定度分配扩散深度估计的推理步数。
- 不变项：区域级分配；不确定度是调度依据；任务仍是深度估计。
- 候选 insight：固定步数可能忽略不同区域在推理过程中的异质性；若不确定度能够反映区域对进一步推理的需求，就可以按需分配计算。
- 文献支持：填写实际读到的页/节；没有则保留待查，不能填虚构 paper ID。
- 动机实验 M1：在同一已有模型与数据上保存多步预测，按预定义不确定度分组，测量追加步数后的区域误差变化；控制总步数/基础模型等条件，查看关系是否稳定。
- 支持分支：若不确定度能够区分追加推理的收益，进入基于不确定度的分配设计。
- 相反分支：若无法区分，当前 insight 未获支持；记录实际结果，调整解释或提出明确变体，不把结论写成支持。
- Method 过渡草稿：`[M1 的真实观察待填] 提示……，因此我们采用……原则，并据此设计区域预算分配。` 缺数据时保持假设式方案，不填入肯定结果。
- 消融 A1：在所提出方法中移除不确定度输入、改用随机或统一分配，回答该模块是否贡献效果；它不能代替 M1 的机制动机分析。
- 可选变体：把调度信号改为预测边际收益，这是机制变化，单列供选择；不得把它默认为主方案，再悄悄把用户 idea 降为基线。

## 进入下一阶段时带走什么

带走原 idea 与锁定机制、insight 卡、M 类实验及 Method 过渡草稿、实际已知证据和未验证点。用这些材料调用实验设计或论文写作能力；不要只转交一个包装后的标题。
